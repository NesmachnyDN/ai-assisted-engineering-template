# Bootstrap Ownership

A template can automate checks, but adoption still needs explicit human ownership.

Recommended roles:

- **Architecture owner** — resolves material architecture blockers and approves durable decisions.
- **Engineering owner** — owns build/test commands, repository quality gates, and implementation readiness.
- **Merge authority** — decides whether reviewed evidence is sufficient to merge.
- **AI implementation agent** — implements one bounded PR inside established constraints.
- **Independent reviewer** — evaluates repository reality rather than implementation claims.

One person may hold several human roles in a small project. What matters is that decision authority is explicit and is not silently delegated to the coding agent.
