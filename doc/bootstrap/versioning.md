# Template Versioning

`VERSION` identifies the reusable template revision, not an application release.

- Patch: wording, examples, and compatible guidance fixes.
- Minor: new compatible workflow capabilities, validators, prompts, or templates.
- Major: changes that require adopters to restructure authoritative project artifacts or materially change the governance contract.

Derived projects are not expected to track this template automatically. Adopt upstream changes deliberately and review them like any other architecture/governance change.
