## Definition of Ready for a bounded PR

A roadmap item is ready when:

- dependencies are complete or explicitly satisfied;
- architecture decisions required for implementation are resolved;
- scope and non-goals are explicit;
- acceptance criteria are observable;
- validation approach is known;
- affected ownership boundaries are identified.

## Definition of Done

A roadmap item is complete when:

- implementation is merged;
- required validation evidence exists;
- mandatory review blockers are resolved;
- documentation/ADRs are updated where required;
- roadmap status reflects repository reality.
